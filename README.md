 # AOOP Project

## Running the project

### Start the server

From the project root, install the server dependencies and start the backend:

```bash
npm install
npm run server
```

The server will start on the port configured by the project (typically `3000`).

### Start the frontend

Open a second terminal, install the frontend dependencies, and start the development server:

```bash
cd frontend
npm install
npm run dev
```

Open the URL printed in the terminal, typically:

```text
http://localhost:5173
```

Keep both terminals running while developing.
